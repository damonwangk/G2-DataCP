夹爪开合不是 0/1
end_state[].position 是连续 float64。本机大寰配置范围为 0–0.025，保留原生行程值；布尔字段 enable、controlled 表示状态，不表示开合量。
SDK 数值范围为 0–0.025；原始反馈与伺服命令的开合方向仍待核对。面板按报文原样显示，不换算为 mm。
“未提供”表示该可选字段没有出现在当前消息中，不补成 0。数值按源字段保存；电流、电压等未核验的比例会明确标注。


name[] 对应等长数值数组。位置用 motor_position（float64，rad），速度用 motor_velocity（float64，rad/s）；点击任一关节查看全部字段。


RGB 是逐帧 JPEG，记录容器是 MCAP
不是 MP4 / H.264 视频文件，也不另外保存一堆 JPG。每帧 JPEG 字节写入 MCAP 的消息；页面连续显示这些帧形成视频预览。JPEG 是相机端已压缩的图像，本采集程序不二次转码。
MCAP 数据块使用 ZSTD 无损压缩；它和图像的 JPEG 编码是两层不同的压缩。不订阅深度通道；已订阅消息的全部原始字段直接保存。
一个 episode 中的实际结构
选定目录 / episode_序号_采集时间 / raw.mcap
/raw/camera/…
RGB Aorta 报文字节保持不变：128 字节传输头 + 相机包头 + JPEG 字节。
/camera/…/image
RGB 的 foxglove.CompressedImage（Protobuf）：format="jpeg"、data=原始 JPEG 字节；timestamp 使用 采集主机接收时间。
/hal/joint_state、/hal/…_ee_data
收到的原始 Protobuf payload，字段不删除、不重编码，schema 内嵌。JSON 表格仅用于前端查看。
/metadata/…
源时间、发布 PTP 时间、采集主机接收时间、序号。时间保留 ns，前端用字符串避免大整数丢精度。
保存策略在 selection_policy.json 附件；/raw 中直接写入收到的完整报文字节，不删字段、不重建报文。源时间与 采集主机时间分属不同的时钟域；三路组帧时间相同不能证明曝光硬同步。原始样本直接保存为 MCAP；采集和显示均不对齐、不插值、不重采样，LeRobot 由独立转换任务生成，采集端不做格式转换。


底盘通道与底盘状态字段不在本面板显示；base_link 仅保留为本体 TF 的参考系名称。本面板只读取接收到的数据，不下发指令。
