# 采集与MCAP预览使用说明

本功能由`robot_recorder_agent.py`接收原始消息，`storage.py`写入和读取MCAP，`app.py`与`static/`提供网页；`recordctl.py`是采集后台CLI。`native.py`解析Aorta封装和Protobuf，`record_filter.py`、`selection.py`定义整话题选择，`frequency.py`、`data_contract.py`提供频率和字段说明。网页通过`LocalStorage`连接本机采集服务；`robot_storage.py`保留客户端和旧远端传输实现，当前`LocalStorage`不自动传输文件。

## 启动与保存一条记录

在机器人Linux终端手动执行：

```bash
cd /data/r2_datacp
./start.sh
./datacp record-dir /data/data/任务A --create
./datacp record-start --label episode
./datacp record-status
./datacp record-stop
```

`record-start`开始写入，`record-stop`结束并保存；录制期间用`./datacp record-next --label episode`保存当前条并立即开始下一条。关闭浏览器不会结束采集。每条保存为`所选目录/任务名称_序号_时间/raw.mcap`和`raw.json`；例如任务名`122episode`得到`122episode_2_20260314_005050/raw.mcap`，默认任务名`episode`仍为`episode_2_时间/raw.mcap`；未正常结束的`.partial`不等于已完成记录。

在网页“原始数据采集”区选择机器人保存目录、勾选完整数据通道，再点击“机器人端开始采集”。选通道影响下一条采集；已选话题按收到的包保存，不因界面范围提醒而裁剪、补值或删除字段。RGB保留源JPEG字节及原包，深度通道当前不订阅。MCAP容器使用可逆ZSTD压缩；网页画面刷新不参与原始落盘。

不经过网页服务，直接访问已启动的采集后台：

```bash
cd /data/r2_datacp
python3 studio/recordctl.py directory --path /data/data/任务A --create
python3 studio/recordctl.py start --label episode
python3 studio/recordctl.py status
python3 studio/recordctl.py episodes
python3 studio/recordctl.py stop
```

它固定访问机器人本机`http://127.0.0.1:18767`，必须先有采集服务。可选`--topics`后跟完整话题名；`--label`用于开始采集，`--path`、`--create`用于目录操作。`recordctl.py`退出后，后台继续采集。不要另开第二个`robot_recorder_agent.py`争用同一个端口。

## 查看原始数据与状态

浏览器访问`http://机器人IP:18769/`。三路相机、本体/夹爪、频率、字段检查器和范围提醒来自服务状态；“冻结读数”只影响该显示面板。接口可单独只读查询：

```bash
api=http://127.0.0.1:18769
curl -sS "$api/api/state"
curl -sS "$api/api/data/catalog"
curl -sS "$api/api/data-contract"
curl -sS "$api/api/control/check"
```

`/api/control/check`读取控制占用与通道状态，不交接控制权。范围提醒使用本体`motor_position`、夹爪`end_state[].position`及配置范围；黄/红提示不修改原始消息，也不能作为实机可执行成功的保证。

## MCAP文件画面预览

在“数据回放”中选择 MCAP，点击“选择文件”浏览机器人目录并选中具体 `.mcap`，也可以输入完整文件或目录路径。采集目录与回放来源独立；采集区显示正在写入/最近保存的完整路径，并提供“查看最近采集文件”。选择文件只读元数据与预览，不执行动作。也可通过API：

```bash
api=http://127.0.0.1:18769
curl -sS -H 'Content-Type: application/json' "$api/api/playback/load" -d '{"file":"episode_1_采集时间"}'
curl -sS -H 'Content-Type: application/json' "$api/api/playback/play" -d '{"speed":1}'
curl -sS -H 'Content-Type: application/json' "$api/api/playback/seek" -d '{"seconds":10}'
curl -sS -X POST "$api/api/playback/pause"
```

`file`可使用机器人上的 MCAP 绝对路径（或包含 raw.mcap 的 episode 目录），旧的当前目录名称仍兼容。`GET /api/mcap/browse?path=目录`浏览文件，`GET /api/mcap/files?path=文件或目录`读取列表，`GET /api/mcap/contents?file=绝对路径`读取通道。这里只刷新文件画面和数据，不发送机器人动作；实机执行用[回放与姿态](回放与姿态使用说明.md)中的独立入口。

查看服务状态及日志：

```bash
systemctl --user status r2-mcap-recorder.service r2-mcap-studio.service --no-pager
journalctl --user -u r2-mcap-recorder.service -n 50 --no-pager
journalctl --user -u r2-mcap-studio.service -n 50 --no-pager
```

采集目录切换前要先结束当前采集或动作任务。整套平台关闭用项目根目录`./stop.sh`；这会结束平台管理的采集、转换及回放任务。
