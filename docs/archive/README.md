# 历史文档

这些文档记录原版转换器、早期部署和验收过程，不是当前平台的操作入口。旧文档中的 `/data/r2_lerobot/tool`、旧 Ubuntu 路径和旧参数仅用于理解历史。当前命令统一见 [使用说明](../../使用说明.md)。

- `conversion/`：原版转换器说明、原机器人环境部署、历史样例验收。
- `studio/`：早期 MCAP 工作台和机器人本地部署验收。

有效运行代码仍在项目的 `studio/`、`conversion/`、`replay/`，历史文档归档不影响运行。旧缓存、日志、一次性 SDK 探测脚本和重复开发备份已删除，逐项清单位于机器人 `deployment/file_organization_20261030.json`。
