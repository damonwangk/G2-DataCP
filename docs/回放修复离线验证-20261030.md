- `replay/trajectory.py`：纯离线的来源适配和时间采样。保存的 action/state 不改写；本机 dahuan 的反馈来源夹爪在发送层使用 `0.025 - feedback`，原始指令不取反。识别工厂与 MCAP 转换的 `provenance/frames.jsonl`；未注释的外部 action 默认按命令读取，不根据数值猜来源。

- inspect 与页面：显示原始首帧及适配后的 SDK 命令；更新开始阶段、来源和发送完成含义。
